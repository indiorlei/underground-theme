# Extension assets

These images are referenced by `package.json` and `README.md`. Add the real
files here before publishing to the Marketplace.

| File | Purpose | Recommended size |
|------|---------|------------------|
| `icon.png` | Extension icon shown in the Marketplace and installed list | 128×128 px, PNG |
| `preview.png` | Screenshot of the theme in use, shown in the README | ~1280 px wide, PNG |

Tips:
- Use a real code file (e.g. TypeScript or JSON) for `preview.png` so the
  syntax colors are visible.
- Keep the icon simple and legible at small sizes.
